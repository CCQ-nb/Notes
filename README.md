# 笔记

手写笔记原稿（扫描件）与配套的电子版整理稿。

## 目录结构

```
笔记/
├── 微积分原稿/          手写原稿扫描，01.jpg–19.jpg（对应 P.01–P.19）
├── 线性代数原稿/        手写原稿扫描，01.jpg–10.jpg
└── 电子版/
    ├── _build/
    │   └── build.mjs    Markdown → HTML 生成脚本（Node.js）
    ├── 微积分/
    │   ├── 微积分笔记.md     源文件，可直接编辑
    │   ├── 微积分笔记.html   浏览器打开即可阅读 / 检索 / 打印
    │   ├── 微积分笔记.pdf    打印版
    │   └── 重新生成.cmd      双击重新生成 HTML
    └── 线性代数/
        ├── 线性代数笔记.md
        ├── 线性代数笔记.html
        ├── 线性代数笔记.pdf
        └── 重新生成.cmd
```

## 原稿

JPEG 扫描件，文件名即页码，与电子版中的「原稿 P.xx」标注一一对应。

## 电子版

电子版保留原稿顺序与措辞，统一记号、补齐排版，公式以 LaTeX 书写。

标记约定：

| 标记 | 含义 |
| --- | --- |
| 【要点】 | 定义、定理与必须记住的结论 |
| 【易错】 | 原稿以 ☆ 标出的易错点与成立条件 |
| 【待确认】 | 字迹模糊、表述有歧义或疑似笔误之处 |
| 【补注】 | 整理者补充，原稿没有，可自行删除 |

### 修改与重新生成

1. 编辑对应目录下的 `.md` 源文件。
2. 双击同目录的 `重新生成.cmd`，或在该目录执行：

   ```bat
   node ..\_build\build.mjs "微积分笔记.md" "微积分笔记.html"
   ```

   需要 Node.js。失败时确认命令行 `node -v` 能显示版本号。
3. 需要 PDF 时，用浏览器打开生成的 HTML，`Ctrl + P` 另存为 PDF。
